# 아이돌 전용 학습 앱으로 — 설계

2026-09-02

## 무엇을 바꾸나

Just는 J-POP 전반을 검색해 공부하는 앱이었다. 이제 **정해진 일곱 그룹만** 다루는
아이돌 학습 앱이 된다. 검색으로 무엇이든 찾을 수 있다는 것이 강점이 아니라,
좋아하는 그룹의 곡이 열자마자 거기 있다는 것이 강점이 된다.

## 그룹 명단

Apple Music 아티스트 ID까지 확인했다. iTunes 공개 API로 조회했고, 그 ID는
MusicKit의 아티스트 ID와 같은 값이다.

| 그룹 | ID | 확인 |
|---|---|---|
| FRUITS ZIPPER | 1617607581 | わたしの一番かわいいところ |
| CANDY TUNE | 1671095780 | |
| SWEET STEADY | 1729116371 | |
| CUTIE STREET | 1763185226 | |
| MORE STAR | 1855752654 | WITH KAWAII論 — KAWAII LAB. 소속 확인 |
| iLiFE! | 1578837625 | アイドルライフスターターパック |
| =LOVE | 1273762750 | |

이름 검색이 아니라 ID를 박는 이유는 동명이인이다. 이름으로 찾으면 어느 날 다른
아티스트가 잡히고, 그 그룹 곡이 통째로 사라진다.

## 곡이 들어오는 길

```
IdolGroup (내장: 이름 · 아티스트 ID · 테마색)
   └→ Apple Music 아티스트 조회 (topSongs / 앨범)
        └→ 곡 목록 → 플레이어 → 가사 · 학습
```

앱에 내장하는 것은 **명단뿐**이다. 곡 목록은 Apple Music에서 온다 — 새 싱글이
나오면 앱 업데이트 없이 뜨고, 아트워크와 길이가 그대로 따라온다.

## 들어내는 것

검색 화면, 내 플레이리스트, J-Pop 차트, 「〈아티스트〉의 다른 곡」 추천, 최근 검색.
그리고 일본 곡 필터(`JapaneseSong`) — 명단 자체가 필터이므로 필요 없다.

지우는 것을 아까워하지 않는다. 검색이 남아 있으면 「아이돌 전용」이 아니라
「아이돌도 있는」 앱이 된다.

## 화면

탭이 셋으로 줄어든다.

| 탭 | 내용 |
|---|---|
| **그룹** (홈) | 그룹 카드 그리드 → 그룹 상세(곡 목록). 위에 「이어서 공부하기」 |
| **단어장** | 그대로 |
| **연습** | 그대로 (듣고 받아쓰기 포함) |

## 재생을 먼저 고친다

지금 구독 없는 계정에서 재생이 실패한다. 원인은 판단 순서다 —
`canPlayFullTracks`가 「가능」이라 답하면 카탈로그 재생으로 가고, 그것이 실패하면
`catch`가 곧장 오류를 띄운다. **그런 경우를 위해 만들어 둔 30초 미리듣기 대체
경로가 시도조차 되지 않는다.**

시도해 보고 결정한다. 카탈로그 재생이 실패하면 미리듣기로 떨어지고,
`canPlayFullTracks`도 그때 false로 정정해 화면이 거짓말하지 않게 한다.

아이돌 앱에서 이것이 더 중요하다. 구독 없이도 앱이 동작해야 한다.

## 디자인

**목록과 그룹 화면은 밝고 화사하게**, 그룹별 컬러를 쓴다. 파스텔·핑크·둥근 모서리.

**플레이어와 가사는 지금의 다크를 유지한다.** 가사는 어두운 배경에서 읽기가 훨씬
편하고, 후리가나와 번역의 대비가 전부 다크 기준으로 맞춰져 있다. 아이돌 앱이라도
가사를 읽는 시간이 이 앱에서 가장 긴 시간이다.

아이콘도 새로 만든다 (`Scripts/make-icon.py`).

## 검증

- 그룹 목록·아티스트 조회는 순수 로직과 클라이언트로 나눠 테스트한다.
- 재생 폴백은 실기기에서만 확인된다 — 시뮬레이터에는 Apple Music 계정이 없다.
- 디자인은 스크린샷으로 확인한다.
